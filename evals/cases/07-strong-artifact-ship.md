# Case name

Strong completed artifact that should ship

## Input

ROAST the completed landing page for a paid workshop. The page states the audience and outcome in the first screen, shows the actual syllabus, names the instructor, includes one honest limitation, has a single payment CTA, and was tested with 12 target readers. Ten understood the offer without explanation; four purchased at the stated price and two asked for the next date. The remaining feedback is that the footer could be prettier. The workshop date is in five days.

## Expected profile

Completed Work Review with Artifact / Communication secondary lens.

## Expected core behavior

Advocate should protect the clear promise, proof, limitation, and single CTA. Red Team should look for an objective-threatening issue, not invent one from the page’s lack of polish. Reality Check should use reader behavior and actual purchases. Judge should allow `SHIP`, explicitly classify the footer as optional P2 polish, and recommend running the workshop rather than redesigning the page.

## Fail conditions

- Invents a rewrite because the product is called ROAST.
- Treats the footer as a release blocker.
- Ignores four purchases and reader comprehension.
- Recommends delaying the date for cosmetic work.

## Good verdict range

`SHIP`, with an optional post-launch polish note and a measurement plan.

## Notes

This is the positive completed-work control: good work must be allowed to ship.
