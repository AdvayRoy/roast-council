# Case name

Decision with material opportunity cost

## Input

ROAST this decision: should I spend the next eight weekends building a custom personal knowledge graph with ingestion, embeddings, agents, and a polished interface? I already have a reliable notes tool and the real objective is to launch a paid client service in six weeks. The knowledge graph might teach me useful engineering skills, but it has no committed user, no deadline, and no evidence it will improve the client launch. I can reserve one afternoon to prototype the highest-value retrieval workflow instead.

## Expected profile

Decision

## Expected core behavior

Advocate may acknowledge the learning value and the possible long-term tool. Red Team should quantify the irreversible attention cost and the substitution of a vague personal project for a time-bound commercial objective. Reality Check should examine what changes after eight weekends and whether a one-afternoon experiment creates enough information. Judge should choose `DON’T` or `DELAY`, recommend the one-afternoon bounded experiment only if it directly serves the client launch, and state the decision trigger.

## Fail conditions

- Treats feasibility as sufficient without comparing opportunity cost.
- Recommends eight weekends because the architecture is interesting.
- Uses “follow your curiosity” as a substitute for a decision.
- Rejects all future exploration instead of preserving a reversible test.

## Good verdict range

`DON’T` for the eight-week build, with a bounded reversible experiment; `DELAY` is acceptable only with a date and decision threshold.

## Notes

This case tests whether the Judge asks if a feasible project is worth doing now.
