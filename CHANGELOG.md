# Changelog

## 2.0.0 — 2026-09-07

First v2 release of ROAST Council.

- Generalized the legacy startup-idea roast into seven routed profiles.
- Added a shared constitution, canonical case, evidence ledger, and Judge protocol.
- Added independent Advocate, Red Team, and Reality Check Round 1 positions.
- Added post-freeze cross-examination and decisive Judge rulings.
- Added Quick, Standard, Deep, and Hard modes with separate depth/aggression controls.
- Added completed-work review with `SHIP`, `FIX THEN SHIP`, and `REWORK`.
- Added overbuilding, opportunity-cost, salvage, and evidence-sensitivity checks.
- Added Re-ROAST belief-delta behavior.
- Added 12 required regression/evaluation cases and a dependency-free validator.
- Packaged the system as a native `.codex-plugin` skills-only plugin with a repo marketplace.
